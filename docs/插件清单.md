# 定制组件清单

统一发布包为 `@forst/dsh-toolkit@0.1.1`。其中两个原生插件来自已部署的独立版本，统一包另外补入原生请求认证和可配置采样地址。

| 组件 | 原独立版本／类型 | 包内位置 |
| --- | --- | --- |
| 服务器 CPU、内存、硬盘和 Go 月额度 | `@forst/dsh-server-metrics@0.1.6` | `plugins/server-metrics` |
| Pi 会话累计费用及分项浮窗 | `@forst/dsh-session-billing@0.1.4` | `plugins/session-billing` |
| Camoufox Browser Use provider、持久浏览器和 MCP 桥接 | 运行时接入组件 | `integrations/camoufox` |
| OpenCode Go / DeepSeek V4.1 Flash Max | 配置预设 | `examples/opencode-go.cordis.patch.yml` |
| 整机采样、systemd 安装、Nginx 配方 | 部署辅助组件 | `host`、`scripts`、`integrations/camoufox` |

“浏览器桌面”本身来自上游 `@runzhliu/dsh-browser-desktop`；本仓库提供其 Camoufox 接入和部署配方，不把上游插件计为自编插件。

Go 模型通过原有 Pi 适配器接入，没有新增一份模型 SDK。Clash 订阅、规则和客户端代理属于具体环境配置，不作为该插件包的一部分。
