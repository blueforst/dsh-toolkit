# 服务器定制组件清单

服务器发布包为 `@forst/dsh-toolkit@0.2.1`。个人电脑的额度与费用增强使用独立的 [`@forst/dsh-toolkit-local`](https://github.com/blueforst/dsh-toolkit-local)。

| 组件 | 维护来源 | 服务器包内位置 |
| --- | --- | --- |
| 服务器 CPU、内存、硬盘 | 本仓库，沿用 server-metrics 0.1.6 基线 | `plugins/server-metrics`、`host` |
| OpenCode Go 月额度 | 本机仓库的固定提交快照 | `vendor/dsh-toolkit-local/plugins/opencode-go-quota` |
| Pi 会话累计费用与分项浮窗 | 本机仓库的固定提交快照 | `vendor/dsh-toolkit-local/plugins/session-billing` |
| Camoufox Browser Use provider、持久浏览器和 MCP 桥接 | 本仓库原服务器运行时配方 | `integrations/camoufox` |
| Linux 完整桌面和 CUA | 本仓库原 Xfce／官方 provider 接入配方 | `integrations/linux-desktop` |
| OpenCode Go 模型配置示例 | 配置预设，不新增模型 SDK | `examples/opencode-go.cordis.patch.yml` |
| systemd 采集器安装、Nginx 配方 | 服务器部署辅助 | `scripts`、`integrations/camoufox` |

通用快照的完整提交号、版本与哈希见 `vendor/dsh-toolkit-local.source.json`，更新流程见 [拆分与版本复用](拆分与版本复用.md)。不手改 vendor、不同时安装两个成品。

“浏览器桌面”本身来自上游 `@runzhliu/dsh-browser-desktop`；本仓库提供服务器运行时接入，不把上游插件计为自编插件。本机版完全沿用 DSH 原生浏览器和 CUA，不携带这里的服务器集成。

Clash 订阅、规则和客户端代理属于具体环境配置，不作为两个插件包的一部分。Magic Context 仍为独立项目。
